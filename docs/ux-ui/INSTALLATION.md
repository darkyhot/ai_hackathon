# Проверка интерфейса в ветке ux/ui

Основа — all_branch, коммит f2f5ee9deed468aacd897b4d6016fe5a95238f69. Эта ветка содержит изменения рабочего frontend и тесты. Сайт domclick-agent.cikada-tech.com автоматически не обновлялся. Объединение с all_branch и развёртывание выполняются отдельно после проверки.

## Как проверить

Открыть ux/ui в отдельном checkout, установить обычные зависимости проекта. Для DOM-проверки нужны Node.js 24 и тестовая зависимость JSDOM:

```bash
npm install --prefix tests/ui
python tests/ui/run_checks.py
```

Проверка запускает настоящий backend с тестовой моделью и подготовленными объявлениями, без платных API и звонков. Результаты и ограничения браузерной проверки — в CHECKS.md.

Для ручного просмотра запустить приложение обычным способом проекта в тестовой среде. Корень сайта обслуживается из штатного frontend; папка design/prototype не используется. Заголовок: «Предложения разных площадок в одном поиске», верхняя полоса этапов скрыта. Маркер HTML: katya-integrated-2026-11-01.

## Что перенесено

Согласованный заголовок, окно входного запроса, вопросы и подтверждения в основной области экрана, редактирование бюджета и финансовой анкеты, оформление ипотечных сценариев и передача предпочтения агенту, подробности критериев квартир, проверка выбранных, более быстрые текстовые реплики разговора. Аккаунты, история, HTTP/SSE, голос, телефония и дальнейшая сделка используют существующий код команды.

## Границы

Последовательностью вопросов и результатами управляет сервер. Демонстрационные квартиры и подготовленные ответы прототипа не подмешиваются. Клиентская скидка 0,6 п.п. не добавлена к серверным ставкам: текущий API её не поддерживает. Ипотечный выбор отправляется агенту сообщением, без обещания банковского одобрения или автоматической фиксации всех параметров сделки. Просмотр показывает время из серверного разговора; самостоятельная смена слота с записью не реализована в текущем серверном контракте. Общий порог совпадений 70% из старой olga/dev не добавлен: используется актуальная логика all_branch.
