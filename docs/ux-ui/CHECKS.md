## Повторить проверки

Использовать настроенную Python-среду проекта с зависимостями из requirements.txt. Для тестов HTTP нужен httpx. Для DOM-проверки нужен Node.js 24 и отдельная dev-зависимость JSDOM; серверному приложению npm не нужен.

```bash
npm install --prefix tests/ui
python tests/ui/run_checks.py
```

Скрипт поднимает тестовый backend на локальном порту 8792, запускает интерфейсную проверку и останавливает сервер. Он использует стандартный tests/e2e/server.py команды и временную тестовую БД.

Для четырёх API-сценариев запустить в первом терминале `python -m tests.e2e.server --port 8790`, во втором — `python -m tests.e2e.scenarios --base http://127.0.0.1:8790`.
