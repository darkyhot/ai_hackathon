# План ветки nas_features (к встрече в четверг)

## Что уже есть в main (Влад, 20.10)
Рабочий прототип ~6 тыс. строк, 18 тестов проходят: разбор запроса голосом/текстом, уточняющие вопросы,
финансовый помощник (накопление взноса на продуктах Сбера, 3 стратегии, график), реальные объявления Циана,
справедливая цена по аналогам, подбор с «Нравится / Не то», проверка рисков по тексту объявления,
звонок продавцу (ИИ-продавец или человек) с жёсткими рамками торга в коде, план сделки, вкладка ROI.
Других веток пока нет.

## Пробелы относительно наших описаний
1. **Объяснение условий ипотеки** — в плане команды есть, в коде нет: везде одна рыночная ставка 16,9%.
   Нет семейной ипотеки, маткапитала, новых условий с 01.10.2026 (ставка зависит от числа детей).
   Для персоны Анны (Казань, ребёнок 4 года, вторичка) это ключевое: семейная на вторичку в Казани,
   скорее всего, недоступна (правило «не более двух строящихся МКД в городе») — агент должен это объяснить.
2. **Нет единого промпта агента.** План команды (п. 2–4) предполагает «исходный промпт», а в репо —
   6 модульных промптов (prompts.py). Каждому к четвергу нужна общая база.
3. **Клиент не может просто спросить агента** («что такое СБР?», «почему справедливая цена такая?»):
   /message понимает только ответы на уточнения и пожелания к подборке.
4. Демо-режим без сети (ROADMAP «до защиты») не сделан.
5. Ставки продуктов финпомощника — допущения (вклад 12%, счёт 10%); ключевая сейчас 14%.

### Что умеет агент теперь
- Понимает из запроса детей, возраст младшего и маткапитал («у нас сын 4 года, есть маткапитал»); если не сказано — один раз спрашивает формой «Семья и маткапитал».
- Проверяет семейную ипотеку по условиям с 01.10.2026: ребёнок до 7 лет, шкала ставок и лимитов по числу детей (регионы / Москва и СПб), вторичка только в городах, где почти не строят, лимит кредита, субсидия 15 лет.
- Объясняет простыми словами: подходит / не подходит и почему, разница платежа в рублях, альтернатива («в новостройке по семейной платёж был бы 52 700 ₽ вместо 105 600 ₽»).
- Маткапитал идёт во взнос: план накоплений и «не хватает» пересчитываются (Анне: 6 100 ₽ вместо ~743 тыс. ₽).
- Дальше все расчёты — сценарии ипотеки, план сделки, «−X ₽ в месяц за каждые 100 тыс. торга» — по ставке выбранной программы.
- Не додумывает тип жилья молча: понимает «новостройка / вторичка» из запроса, а если не сказано — говорит, что ищет на вторичке (так устроен MVP).
- Отвечает на вопросы посреди работы («что такое СБР?», «сколько я переплачу?») — подборка и подтверждения при этом ждут дальше.
- Демо-режим без сети: `DEMO=1 LLM_PROVIDER=mock .venv/bin/uvicorn backend.main:app --port 8000`.
- Новостройки: живой поиск Циана проверен на Казани (12 объявлений: 5 от застройщика по ДДУ, 7 переуступок); переуступка — свой план сделки через СБР.
- Две площадки: Циан и Домклик опрашиваются параллельно; одна квартира с двух сайтов — одна карточка (в демо по Казани склеено 18 дублей).
- Тесты: 67 (было 18), новые — `tests/test_mortgage.py`, включая прогон шага «Финансы» для Анны.

### Как проверить
```bash
git checkout nas_features
LLM_PROVIDER=mock .venv/bin/uvicorn backend.main:app --port 8000      # без ключа LLM
.venv/bin/python -m unittest discover -s tests -v                      # тесты
```
Запросы для демо:
- «Двушка в Казани до 9 млн, ипотека, на взнос ещё копим, сын 4 года, есть маткапитал» — семейная не проходит (Казань), сравнение с новостройкой, маткапитал во взнос.
- «Двушка в Казани до 9 млн, ипотека, на взнос хватает» — агент спросит про детей.
- «Двушка в Москве до 15 млн, ипотека, двое детей, младшему 3 года» — тип жилья не назван: агент говорит вслух «ищу на вторичном рынке», объясняет, что в Москве семейную на вторичку не дают, и сравнивает с новостройкой (10%).
- «Двушка в Казани до 9 млн в новостройке, сын 4 года, есть маткапитал» — агент честно говорит, что поиск новостроек пока не подключён, но считает для новостройки семейную ипотеку.

Условия ипотеки сверены 21.10.2026 по открытым источникам (Минфин через КонсультантПлюс, Финуслуги, myfin, Гарант) — перед защитой проверить ещё раз.
